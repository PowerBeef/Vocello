Help and Support

Last updated: October 22, 2026

Get help with Vocello for Mac or iPhone, or with the vocello command line. Support is handled directly by the Vocello maintainer, and response time varies with the issue.

For reproducible product issues, you can also open a GitHub issue.

Before contacting support

  1. Confirm that the required voice model shows Ready: on a Mac in Settings, Models & Files; on iPhone in Settings, Voice Models; in the terminal with vocello models list.
  2. Confirm that the device has enough free storage for the selected model and generated audio.
  3. For microphone or transcription problems, review Vocello permissions in Apple Settings.
  4. For an interrupted model download, keep Vocello installed and use the visible Retry or Remove action.

What to include

  • Vocello version and build number from Settings, or the output of vocello --version.
  • macOS or iOS version.
  • The Studio mode and model status involved.
  • The visible error title or sanitized error code. For the command line, the error code and exit status that --json reports.
  • The steps immediately before the issue occurred.

Command line help

The installer package Vocello-macos26-cli.pkg puts the command line in /usr/local/lib/vocello and links /usr/local/bin/vocello and its zsh completion; it asks for an administrator password. The command line shares the Mac app's models, saved voices, and settings.

  • vocello --version shows the installed version and build. If the shell cannot find vocello after installing the package, open a new Terminal window. The installer adds links only in folders that root alone can change, so if your /usr/local/bin belongs to your user (as some older Homebrew setups leave it), run /usr/local/lib/vocello/vocello or link it into your path yourself.
  • vocello doctor checks the shared data folder, the bundled model contract and catalog, the installed models, the Mac's memory tier, and free disk, without loading a model. Add --json for a machine-readable report.
  • vocello models list shows what is installed, and vocello models verify checks every installed file's size and SHA-256 digest.
  • An exit status of 75 means the engine or a store is busy, memory is short, or the network is unavailable: retry later. On an 8 GB Mac, one engine runs at a time, so quit the app or the other command first. vocello history reads History only while the Vocello app is closed.
  • Takes made with the command line are saved as files and do not appear in History yet.
  • If you copied the Vocello CLI folder from Vocello-macos26-cli.dmg instead, run its executable by its quoted full path and keep the folder's executable and resource bundles together.
  • To remove the installer package's copy, run sudo sh /usr/local/lib/vocello/uninstall.sh. It keeps your models, saved voices, and History. Remove a copied folder by deleting it.

AI agents (vocello mcp)

vocello mcp serves Claude Code, Claude Desktop, and other MCP clients over standard input and output on your Mac. To add it to Claude Code for every project, run:

claude mcp add --scope user vocello -- /usr/local/bin/vocello mcp

  • vocello mcp --print-config claude-code prints that command, and vocello mcp --print-config claude-desktop prints the setup for Claude Desktop.
  • vocello mcp --self-test runs a scripted session without loading a model, to check the server on its own.
  • Cloning a voice or saving one needs consent in each request. Files that a request names stay in Vocello's output folder unless you start the server with --allow-dir.

For a reproducible command line or MCP issue, open a GitHub issue with the command or tool name, the version, the exit status, and the error code, without your script text or file paths.

Protect your privacy

Do not send scripts, generated clips, reference recordings, cloned voices, transcripts, device serial numbers, account secrets, or absolute file paths. Support should be able to begin diagnosis from product version, operating-system version, model state, and a sanitized error code.

Security reports

Do not disclose a vulnerability in a public discussion. Use the repository's private security advisory form.
