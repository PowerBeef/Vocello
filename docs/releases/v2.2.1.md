# Vocello 2.2.1

Released **2026-07-25**. A same-day packaging patch on top of
[2.2.0](v2.2.0.md): it makes the app bundle App Store Connect-clean so the first iOS
TestFlight build can ship from the same tag, and hardens the release lane that produces it.
No feature, engine, or behavior changes; on macOS the app is functionally identical to
2.2.0.

> **Upgrading?** Nothing to do beyond the usual drag-install if you want the version number
> to match; 2.2.0 behaves identically. Installed models, history, and saved voices carry
> over automatically.

[Download v2.2.1](https://github.com/PowerBeef/Vocello/releases/tag/v2.2.1) · [All releases](https://github.com/PowerBeef/Vocello/releases)

## Requirements

Unchanged from [2.2.0](v2.2.0.md#requirements): macOS 26.0+, Apple Silicon, 8 GB RAM
minimum, ~7 GB free disk for the Speed variants, internet for one-time model downloads.

## What changed

- **One version identity for every embedded framework.** The generated framework
  Info.plists previously carried no `CFBundleShortVersionString` because the version was
  pinned only on the app targets; App Store Connect rejects embedded frameworks missing
  that key (upload error 90057). `project.yml` now defines `MARKETING_VERSION` /
  `CURRENT_PROJECT_VERSION` once at project scope and every target inherits them.
- **Full-bleed opaque iOS app icons.** The iOS icon set carried pre-rounded corners with an
  alpha channel; App Store Connect rejects a transparent large icon (upload error 90717).
  The artwork now extends to the full square and every size is opaque — visually identical
  on device, since iOS applies the corner mask itself. The macOS icon is unchanged.
- **Release-lane hardening for the iOS archive path** (workflow-side, landed on `main`
  during the 2.2.0→TestFlight arc): the managed archive command delivers its literal
  destination quoting to the required-step ledger; the App Store provisioning profile is
  scoped to the app target through a runner-temp xcconfig macro instead of a global
  xcodebuild override (which SPM targets reject); and the CI IPA export signs manually with
  an explicit bundle-id → profile mapping because cloud-managed automatic signing needs an
  Admin-role App Store Connect key the CI key deliberately is not.

## Evidence

- Deterministic release gates: project inputs, macOS build, deterministic tests, and the
  iOS device-SDK compile run in the managed release process on the tag, per the schema-v2
  release-evidence contract.
- macOS smoke lane: **deliberate skip** for this candidate — the patch changes packaging
  metadata and iOS icon assets only (no macOS behavior surface); the 2.2.0 evidence
  (`macos-xcui-smoke-20260725-062451-8f15c1fd`, PASS including the 12-segment long-form
  memory proof) stands for the unchanged macOS surface.
- Engine benchmarks: not applicable (no engine change); the 2.2.0 `release-QA-2.2.0` bench
  label remains the current reference.

## Known limitations

Unchanged from [2.2.0](v2.2.0.md#known-limitations).

## Install

1. Download [`Vocello-macos26.dmg`](https://github.com/PowerBeef/Vocello/releases/download/v2.2.1/Vocello-macos26.dmg).
2. Open the DMG and drag `Vocello.app` into `/Applications`.
3. Launch, open Settings, and download the model variants you want.
