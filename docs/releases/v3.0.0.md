# Vocello 3.0.0

**Unpublished candidate — build 24.** Version 3.0 brings together safer audio storage,
clearer voice enrollment, more reliable request handling, and a separate downloadable CLI
package. The public Mac release remains 2.4.0. These notes describe implemented changes;
they do not announce a download, a verified candidate, or an App Store submission.

## What's new

- **Protect accepted audio when an operation fails.** Failed generation cleans up its own
  staging files rather than deleting an existing output destination. Saved Voice transactions
  retain recoverable backups when restoration fails, and app/CLI store mutations use a shared
  cross-process lock. Contention reports a busy store instead of attempting competing recovery.
- **Safer long-form updates.** Segment replacement stages and checks candidate audio and the
  project manifest before acceptance. Recovery records protect interrupted updates, previous
  joined outputs retain their History ownership, and reused segments count once in progress.
  Continuing generation remains session-scoped; this is not automatic background resume.
- **Review imported Clone references before saving.** iPhone Studio's Reference Clip picker
  includes Import audio file. Imports use permanent voice enrollment with on-device
  transcription, editable text, explicit audio-only confirmation when needed, and Save Voice
  confirmation. A delayed transcription cannot overwrite manual edits. macOS enrollment also
  retains typed transcription outcomes and reference-language metadata.
- **Keep output language separate from reference language.** Clone reference metadata no longer
  silently selects the generated language. Explicit output-language choices remain authoritative.
  macOS Voice Design snapshots language, delivery, variation and pinned seed before asynchronous
  startup, so later UI edits cannot alter the submitted request.
- **Clearer delivery expectations.** The picker offers Neutral, Calm, Whisper and Sad as its
  measured delivery group; Happy, Angry, Fearful and Surprised remain directional hints, not
  promises of exact emotion. Excited has folded into Happy and Dramatic has been retired from
  the current roster. Existing raw delivery instructions remain verbatim for reproducibility.
  Automatic acoustic analysis is not proof of listener-perceived improvement.
- **A self-contained CLI distribution.** The release workflow now prepares a separate arm64
  CLI DMG with resource bundles, licenses and usage instructions. Batch processing preserves
  completed outputs and reports failed, cancelled and unattempted items. CLI bookkeeping stays
  outside ordinary engine requests, and signal cancellation awaits owned cleanup.
- **More dependable completion and recovery.** History-save failures remain distinct from
  successful synthesis, with recovery/export paths. Stale completion callbacks cannot take
  over a newer Mac generation's player. Explicit Play after streaming follows the heard
  position rather than assuming all queued audio was played.

## Requirements

- macOS 26.0 or later, Apple Silicon, and at least 8 GB unified memory.
- iPhone support targets iOS 26.0 or later and iPhone 15 Pro or newer supported hardware.
- Internet access for initial model downloads from Hugging Face; model files are not bundled.
  Check the displayed model sizes and available storage before installing. Generation runs
  locally after the necessary model is installed.
- Microphone access for recording and on-device Speech Recognition availability for automatic
  transcription. Manual transcript review remains available when recognition cannot finish.

## Install

Once a candidate is explicitly qualified and published, obtain it from the
[official releases page](https://github.com/PowerBeef/Vocello/releases).

1. For the Mac app, open `Vocello-macos26.dmg` and install `Vocello.app` in Applications.
2. For command-line use, open `Vocello-macos26-cli.dmg` and copy the complete **Vocello CLI**
   folder to a user-owned location. Keep its executable and resource bundles together; no
   privileged installer or shell-profile change is required. Begin with `vocello --help`.
3. Review the model manager before downloading. Back up important exported audio and saved
   references before upgrading; current-candidate upgrade acceptance is still required.

Do not use these future artifact names as evidence that a 3.0 package is already available.
The existing TestFlight beta does not imply that build 24 has been uploaded or approved.

## Evidence and limitations

Behavioral regression tests cover request preservation, transactional failure recovery,
cross-process exclusion, cancellation and batch support-policy integration. Development-build
UI and generation runs are recorded separately from signed-package acceptance.

The current 3.0 signed/notarized candidate smoke, packaged three-mode and two-item CLI batch
qualification, full 201-take iPhone campaign and App Store candidate checks have **not completed**.
No newer qualified candidate performance record is available; these notes make no throughput
improvement claim over 2.4.0. The existing canonical performance record remains historical.

Known release investigations remain open: some retained French/Chinese takes fail mandatory
audio QC, a long-form take reached its token limit, and some French recognition/prosody evidence
remains inconclusive. A retained French code sequence also produces a long silent gap under an
independent official decoder. Failed takes are not silently regenerated, substituted or accepted.
Privacy/content-rights decisions and candidate-specific signing/account evidence remain release
dependencies. Consult the
[authoritative roadmap](https://github.com/PowerBeef/Vocello/blob/main/docs/ROADMAP.md)
for their current state. No note here waives those gates.

## TestFlight — What to Test (build 24)

These are proposed qualification instructions for an authorized build-24 distribution, not an
announcement that it is live:

- Exercise first launch, model install/cancel/relaunch/removal and offline generation on supported
  hardware; preserve existing personal models and voices.
- Generate Built-in, French Voice Design with a pinned seed, and transcript-backed Clone takes.
  Confirm selected language, saved transcript and reference identity are preserved.
- Import a test-owned reference without a text sidecar, review transcription or manual/audio-only
  fallback, save it, generate a Clone take, then remove only that test-owned voice.
- Generate a long-form project and regenerate one segment. Check the joined result, History and
  playback without losing the prior accepted output after cancellation or failure.
- Exercise Play/Pause, scrubbing, export, cancellation and History recovery. Report silence,
  unusually spaced words, language/pitch mismatch, a stuck player or any missing saved output.

Use TestFlight feedback only on an explicitly distributed candidate, or the
[support page](https://vocello.vercel.app/support/). Do not include private reference audio or transcripts
in public reports.
