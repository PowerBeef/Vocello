Privacy Policy

Last updated: October 22, 2026

Vocello is a local, on-device voice studio for Apple Silicon: a Mac app, an iPhone app, and the vocello command line. It is built so your work stays on your device. Vocello does not collect, track, or sell your personal data, and Vocello itself never sends your work off your device.

The short version: the apps and the command line have no account and no analytics. Your scripts, generated audio, recorded reference clips, transcripts, history, and saved voices stay on your device. Vocello's only network requests are downloads of the AI voice models from Hugging Face when you choose to install one, on iPhone, App Store purchases, which Apple handles, and on Mac, if you allow it, a check for a newer version of the app. If you connect an AI agent to vocello mcp, that agent sees what you let it read, and its own privacy terms apply to it.

What Vocello does not do

  • No account, sign-in, or user profile.
  • No analytics, telemetry, advertising, or third-party tracking SDKs in the apps or the command line.
  • No selling or sharing of any data, because none is collected.
  • No transmission of your scripts, recordings, transcripts, or generated audio off your device by Vocello.

Data stored on your device

Everything you create lives in local app storage on your device: typed scripts, generated audio clips, recorded reference clips, their transcripts, your generation history, and any voices you save. Vocello does not upload any of it. On iPhone, your own device backups (iCloud Backup, or a backup to your computer if you use one) include your generated audio, saved voices and history; downloaded models and caches are excluded. Use Vocello's deletion controls when you want to remove individual items or downloaded models. On macOS, deleting the app itself does not remove its Application Support data.

Microphone

Vocello asks for microphone access only when you choose to record a reference clip for Voice Cloning. Recordings are saved locally and used only for the voice you are creating. They are not uploaded.

Speech recognition (transcription)

When you record a reference clip, Vocello can transcribe it to improve clone quality. Transcription runs on your device using Apple's on-device speech recognition. The audio is processed locally and is not sent to a server by Vocello.

Network use

Vocello's own network activity is downloading AI voice model files from Hugging Face, and only when you install a model, in an app or with vocello models install. These are ordinary anonymous file downloads over HTTPS: Vocello sends no account, identifier, script, recording, or generated audio, and receives nothing back except the model files. As with any web server, Hugging Face receives your IP address and standard request details, which it handles under its own privacy policy; Vocello does not receive or keep them. On iPhone, the optional export purchase and Restore Purchases go through Apple's App Store. Voice generation itself runs entirely on your device after the model is installed.

On a Mac, Vocello asks on its second launch whether to check for updates automatically, and you can change this at any time in Settings > Updates or check by hand from the Vocello menu. A check downloads a small signed list of releases from GitHub, at most once a day when automatic checks are on, and an update you choose to install is downloaded from GitHub. These requests send no account, identifier, script, recording, or generated audio, and no profile of your Mac. As with any web server, GitHub receives your IP address and standard request details, including the app's version, which it handles under its own privacy statement; Vocello does not receive or keep them. Every update is signed, and the app checks that signature before installing it.

Marking on generated audio

Every WAV file Vocello 3.0 generates, in the Mac app and the command line, carries an inaudible AudioSeal watermark with a fixed Vocello payload and a short provenance note naming the generator, its version, the engine, the model, the mode, and the creation time, so the file can be identified as AI-generated. The marking is the same for everyone: it holds no account, device, or personal identifier, and nothing about it is sent anywhere. Only generated takes are marked: reference clips you record or import are not, and neither is live preview audio heard before the file is written. The iPhone app adds this marking with its 3.0 version; the 2.4 public beta does not mark its files.

The vocello command line

The vocello command line runs on your Mac and uses the Mac app's local data folder, ~/Library/Application Support/QwenVoice: the same models, saved voices, and settings, and it reads the app's History. Takes it generates are saved as WAV files, by default in outputs/cli inside that folder, or where you choose. When a request carries a client request ID, its result is kept in that folder for seven days so a retry can replay it instead of generating again.

Its only network activity is the Hugging Face model download described above, when you run vocello models install or vocello models install-recommended. Generation and voice enrollment run on your Mac. When it transcribes a reference clip, it uses Apple's on-device speech recognition, and by default only when Speech Recognition is already allowed for your terminal, so it does not prompt unless you ask it to.

AI agents and vocello mcp

vocello mcp lets an AI agent you set up, such as Claude Code or Claude Desktop, use Vocello through the Model Context Protocol. The agent starts the server on your Mac and talks to it over standard input and output only: the server opens no network port and makes no network request of its own, except a model download when you start it with --allow-model-install and the agent asks for one.

The agent sees what its requests return, which can include saved voice names and transcripts, History text, settings, and file paths, and it may send that to its own AI service under that service's terms. Vocello does not control what the agent does with it. Cloning a voice or saving one needs consent in each request, and a file that a request names is read or written only inside Vocello's output folder unless you start the server with --allow-dir.

Optional export

You may optionally choose a Files or iCloud Drive folder so that each new generated clip is also copied there. This is entirely under your control and uses only the folder you pick. Generated clips are always also kept in the app for History.

Deleting your data

  • Delete individual generations, or clear all history, from the History screen.
  • Delete saved voices from the Voices library.
  • Delete downloaded models from Settings.
  • On macOS, deleting the Vocello app does not delete its models, voices, outputs, history, or diagnostics from ~/Library/Application Support/QwenVoice. Remove that folder separately only after exporting anything you want to keep.
  • Removing the command line, with sudo sh /usr/local/lib/vocello/uninstall.sh for the installer package or by deleting a copied Vocello CLI folder, leaves that same data folder, including the takes in outputs/cli, in place.
  • On iPhone, use Vocello's visible deletion controls to remove models, saved voices, generated audio, and history before uninstalling when you need an explicit deletion workflow.

This website

This site (vocello.vercel.app) is hosted on Vercel and uses Vercel Web Analytics, a cookieless, aggregate count of page visits. It sets no cookies, stores no identifiers on your device, and does not follow you across sites. The apps and the command line contain no analytics of any kind.

Children

Vocello does not knowingly collect personal information from anyone, including children. Because Vocello collects no data, there is nothing for it to gather.
